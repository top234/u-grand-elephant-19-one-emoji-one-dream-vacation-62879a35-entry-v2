## The entry

🌌

One emoji, nothing else — that is the whole entry.

## Why this emoji

A mountain is a postcard you look at. A night under the Milky Way is a
night you live: no hotel, no itinerary, just a blanket in the desert and
a sky full of stars. It is the trip that makes a stranger want to book a
flight — dark skies you can never see from a city, in the Atacama, the
Sahara, the Namib. Once in a lifetime.

## Run it

```sh
node main.ts
```

`main.ts` writes exactly one emoji, U+1F30C MILKY WAY (🌌), to
`$OUTPUT_DIR/entry.txt` (default `/output`) — 4 bytes, no newline, no
other text. It verifies after writing that the file contains exactly
that one emoji.
